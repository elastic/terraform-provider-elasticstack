Advanced settings applied as plain string values, keyed by setting name. A value that looks like JSON, such as `["a","b"]`, is still sent to Kibana as a string. Use this map for text settings and for settings that store JSON text as a string, and use `json_settings` for settings that hold a boolean, number, array or object. Each key must be between 1 and 1024 characters long and can be declared in only one of `string_settings` and `json_settings`. A null value is not accepted: to reset a setting to its Kibana default, remove the key.

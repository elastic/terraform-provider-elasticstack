Advanced settings applied as JSON values, keyed by setting name. Each value is JSON text and keeps its JSON type in Kibana: a boolean (`false`), a number (`0`), an array (`["@timestamp","message"]`), an object, or a string. Use `jsonencode(...)` to build the text. A value that Kibana returns with different whitespace, object key order or number formatting than you configured does not show as drift. Reformatting a value in your own configuration can show as an in-place update that changes nothing in Kibana. Each key must be between 1 and 1024 characters long and can be declared in only one of `string_settings` and `json_settings`. A null entry and the JSON value `null` are not accepted: to reset a setting to its Kibana default, remove the key.

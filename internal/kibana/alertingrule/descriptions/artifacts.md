Linked assets for the alerting rule: an investigation guide and/or references to related dashboards, so that runbooks and context are co-located with the alert configuration as code. At least one of `investigation_guide` or `dashboards` must be set. Requires Elastic Stack 9.1 or higher to write; on stacks older than 9.5.0 the Kibana GET API does not return artifacts (elastic/kibana#247279), so `terraform import` will not populate this block and external changes to artifacts made outside Terraform will not be detected by refresh. Omitting this block does not clear artifacts already stored on the rule in Kibana.
